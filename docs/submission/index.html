Submission

Submission Options

  • Full Papers: 8 to 10 Pages, using Eurographics Format
  • Short Papers: up to 4 Pages

In both cases, you may add up to one full page for references.

Submission

Submissions will be handled through the Precision Conference Solutions (PCS) System. For submitting paper, please login to PCS system following this link: PCS
